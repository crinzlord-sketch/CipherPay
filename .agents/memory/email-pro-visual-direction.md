# Email Pro visual direction

Email Pro should feel like a premium private sender console, not a generic admin form. Keep the layout compact and editorial, use orange for deliberate actions and purple as a restrained brand accent, and maintain distinct light and dark surface systems. Dark mode must use deep ink/plum cards, readable muted text, and controlled borders rather than translucent beige surfaces.

**Why:** The first Email Pro treatment read as basic and cheap, with the dark theme especially failing because light-theme translucency carried over into dark mode.

**How to apply:** When changing Email Pro UI, preserve the dense alignment and explicit theme tokens; avoid large empty heroes, noisy gradients, and generic rounded-card styling.
